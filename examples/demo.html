🔍 RequestID Extension Demo

Extension Configuration:
• Prefix: dev
• Pattern: http://127.0.0.1/*
• Server: Running on localhost

Step 1: Make HTTP Requests

Test the RequestID extension by sending requests that should receive the X-Request-ID header:

API Endpoints:
• GET /api/echo - Responds to fetch requests
• GET /api/echo-xhr - Responds to XHR requests

Step 2: Results

Click buttons above to start the demo...

Step 3: Verification

In Chrome DevTools (F12), go to the Network tab and:

  1. Filter for "Fetch" and "XHR" requests
  2. Click each request to inspect headers
  3. Look for X-Request-ID: dev-xxxxx in Request Headers
  4. Compare with server console logs
